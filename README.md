# password-manager

CLI-менеджер паролей на Rust: хранилище с шифрованием AES-256-GCM и ключом из Argon2id.

## Возможности (план)

- один зашифрованный vault-файл на диске;
- ключ выводится из мастер-пароля через Argon2id;
- записи: сервис, логин, пароль, заметка;
- команды: `add`, `get`, `list`, `rm`, `export`;
- автокопирование пароля в буфер обмена с автоочисткой;
- генератор паролей.

## Стек

- Язык: Rust
- Планируемые библиотеки: `clap`, `rpassword`, `argon2`, `aes-gcm`, `rand`, `serde`, `zeroize`

## Сборка и запуск

```bash
cargo build --release
cargo run -- add github
```
